🚀 Cypress.js: Проект автотестов на JavaScript
Этот проект содержит набор автоматизированных end-to-end (E2E) тестов на JavaScript с использованием фреймворка Cypress и системой отчетов Allure.

📋 Предварительные требования
Перед началом работы убедитесь, что на вашем компьютере установлено:

Node.js (версии 16 или выше) и npm

Git — для клонирования репозитория

Allure Commandline (опционально, для генерации отчетов)

🚀 Быстрый старт
Следуйте этим шагам, чтобы быстро запустить проект на своей машине:

Склонируйте репозиторий:

bash
git clone https://github.com/danilalukyanchenkoQA/cypress.js.git
cd cypress.js
Установите зависимости:
Запустите эту команду в корневой папке проекта (cypress.js/). Она установит Cypress и все необходимые пакеты.

bash
npm install
Примечание: В проекте уже есть папка node_modules и package-lock.json, что означает, что зависимости были установлены ранее. Эта команда гарантирует, что у вас будут актуальные версии.

Запустите тесты:
У вас есть несколько вариантов запуска:

Интерактивный режим (рекомендуется для разработки): Открывает Cypress Test Runner, где вы можете визуально выбирать и запускать тесты.

bash
npm run test
# или
npx cypress open
Headless-режим (для CI/консоли): Все тесты запускаются в фоне, результаты выводятся в терминал.

bash
npx cypress run
📊 Генерация и просмотр отчетов Allure
Проект настроен на создание детальных отчетов после каждого прогона.

После выполнения тестов (командой npx cypress run) в папке allure-results появятся файлы с сырыми данными.

Чтобы сгенерировать и открыть красивый HTML-отчет в браузере, выполните:

bash
allure serve allure-results
Для работы этой команды необходим установленный Allure Commandline (см. "Предварительные требования").

📁 Структура проекта
text
cypress.js/
├── cypress/
│   ├── e2e/                 # 📂 Директория для написания тестов
│   │   └── *.cy.js          # 📝 Файлы с тестами (например, LearningTests.cy.js)
│   ├── fixtures/            # 🗃️ Тестовые данные (опционально)
│   └── support/             # 🛠️ Вспомогательные файлы (commands, etc.)
├── allure-results/          # 📊 Папка с сырыми данными отчетов Allure (генерируется)
├── cypress.config.js        # ⚙️  Конфигурационный файл Cypress
└── package.json             # 📦 Файл зависимостей и npm-скриптов
✍️ Написание новых тестов
Все новые тесты должны создаваться в папке /cypress/e2e.

Файлы тестов должны иметь расширение .cy.js (например, login.cy.js).

Cypress автоматически обнаружит их в Test Runner.

🛠️ Полезные команды
Команда	Назначение
npm run test или npx cypress open	Запуск интерактивного Test Runner.
npx cypress run	Запуск всех тестов в headless-режиме.
npx cypress run --spec "cypress/e2e/имя_файла.cy.js"	Запуск одного конкретного тестового файла.
allure serve allure-results	Генерация и открытие отчета Allure.
allure generate allure-results --clean -o allure-report	Создание статического отчета в папку allure-report.
🔧 Возможные проблемы и решения
"Error: ... No version of Cypress is installed": Убедитесь, что команда npm install выполнилась без ошибок. Можно принудительно переустановить Cypress: npm install cypress --save-dev.

Ошибки при запуске allure serve: Убедитесь, что Allure Commandline установлен глобально и добавлен в PATH системы. Подробности в официальной документации.
